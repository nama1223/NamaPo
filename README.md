## 概要

テンポを「聴いて当てる」「体で刻む」トレーニングアプリ。確かなテンポ感覚を身につけるための、ゲーム感覚の練習道具です。

### 聴き取りトレーニング
鳴らされるお題のテンポを、選択肢から選ぶ／数値で入力する2方式。制限は 無制限／生き残り（ライフ制）／60秒 から選べます。

### タップでトレーニング
お題テンポの数値を見てタップする「自力タップ」、お手本を８拍聴いてから続きをタップする「テンポキープ」、お手本の後にわざとズラして鳴り続ける「妨害」モード。

### その他
結果はポイント制で履歴に残ります。お題テンポのリストは編集可能。音の種類や選択肢の近さ（難易度）も設定できます。

### 画面説明（スクリーンショットの見方）
1) モード選択: 6つのトレーニングと、履歴・設定への入口。
2) 聴き取り: ▶で8拍聴いて、4つの選択肢から選ぶ。
3) 判定: 正解でポイント加算、連続正解も表示。
4) 自力タップ: お題に合わせて8回タップし、自分のズレを判定。
5) 設定: 音色・拍の表示方法・難易度・お題リストの編集。
